# Plinko - Concrete Powder Replenishment Tank

**Description:**
Design and install a concrete powder replenishment system for the Plinko machine. Currently, the system uses a piston feed tape to drop blocks, but it requires manual reloading. 

**Technical Notes:**
- Build a detection circuit to monitor when the concrete powder magazine is empty (or missing blocks).
- Build a storage silo/tank (likely utilizing droppers/dispensers or a gravity-feed system) to automatically inject new concrete powder blocks into the piston feed tape when a drop is detected.
- This ensures the machine is 100% autonomous and doesn't require constant maintenance to refill the playing pieces.
